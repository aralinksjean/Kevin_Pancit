This folder is reserved for official branding assets (e.g. logo.png / logo.svg).

To use a real logo:
1. Add your logo file here, for example: assets/branding/logo.png
2. Open js/config.js and set `logo.imagePath` to "assets/branding/logo.png"
3. The text wordmark will automatically be replaced by your logo on every page.

No logo file is included yet — the site currently displays a text wordmark instead of inventing one.
